# 현장 안전 안내 포털 사용법

건설현장 안전보건 안내와 법령 개정 확인을 한 화면에 모은 안내·연습용 웹 페이지입니다. 설치나 서버 없이 `index.html`을 열면 동작합니다.


## 1. 열어 보기

1. 이 폴더의 `index.html`을 더블클릭합니다. (Chrome, Edge 권장)
2. 상단 메뉴에서 원하는 항목을 누르면 해당 위치로 이동합니다.
3. 첫 화면 배경 영상은 같은 폴더의 `gemini-generated-video-08a36b57-no-caption.mp4`입니다. 소리 없이 반복 재생됩니다.

다른 사람에게 줄 때는 `index.html`만 보내지 말고 **폴더 전체**(영상·`files` 폴더 포함)를 함께 보내세요. 파일이 빠지면 영상이 나오지 않고 자료실 다운로드가 되지 않습니다.

## 3. 화면 구성

상단 메뉴 순서대로입니다.

| 메뉴 | 쓰는 방법 |
| --- | --- |
| 홈 | 포털 소개와 안내 문구 |
| 역할 | 현장 안전을 지키는 5가지 역할과 하는 일 |
| 일일 사이클 | 매일 반복하는 안전 활동 순서 |
| 위험성평가 | 빈도(1~5)와 강도(1~5)를 고르거나 표의 칸을 눌러 위험도 점수·등급·감소대책 우선순위 확인 |
| 점검 체크리스트 | 작업 종류 탭을 고르고 항목을 체크하면 진행률이 표시됨 |
| 재해 지표 | 숫자를 입력하면 재해율·도수율·강도율을 계산(소수 둘째 자리 반올림) |
| 안전관리비 | 공사금액에 계상 요율을 곱하고 고정 금액을 더해 안전보건관리비 계상액 확인(원 단위 미만 반올림) |
| 사고 대응 | 4단계 중 하나를 누르면 행동 요령이 크게 표시됨 |
| 법령 개정 | 확인한 법령 개정 항목을 정리한 카드 |
| FAQ | 질문을 눌러 답변을 펼침, 검색창과 카테고리 버튼으로 걸러 보기 |
| 자료실 | `files` 폴더의 파일을 목록(파일명·설명·용량)으로 보여 주고, 다운로드 버튼으로 바로 내려받음 |
| 공통 기능 | 상단 해·달 버튼으로 라이트/다크 모드 전환(선택은 이 브라우저에 저장, 처음에는 기기 설정을 따름), 아래로 스크롤하면 우측 하단에 `맨 위로` 버튼 표시, 모바일(폭 860px 이하)에서는 메뉴가 ≡ 버튼으로 접힘 |

계산 결과는 참고용입니다. 공식 산정에는 해당 기준의 정의와 사내 규정을 확인하세요.

## 4. 내용 바꾸기

화면에 보이는 내용은 `index.html` 맨 위의 `★ 수정 영역` 안에서 고칩니다. 메모장이나 VS Code로 `index.html`을 열고 해당 부분만 수정한 뒤 저장하고, 브라우저에서 새로고침하세요. 수정 전에는 파일을 복사해 두는 것을 권합니다.

| 고칠 내용 | 찾을 이름 | 설명 |
| --- | --- | --- |
| 사고 대응 4단계 | `ACCIDENT_STEPS` | 단계별 행동 요령, 보고 기한(`deadline`), 연락처(`contacts`). 기한·연락처는 현재 비어 있으므로 사내 규정·관계 법령·발주처 지침을 확인한 뒤 직접 입력 |
| 법령 개정 카드 | `LEGAL_UPDATES`, `LEGAL_LIST_CHECKED` | 5개 카드. 비워 두면 화면에 "입력 필요"로 표시. 목록 최종 확인일도 함께 입력 |
| 위험도 등급 구간 | `RISK_SETTINGS` | 낮음/보통/높음 경계 점수와 안내 문구. 현재 4점 이하 낮음, 12점 이하 보통, 그 이상 높음(예시). 사업장 위험성평가 기준에 맞게 변경 |
| 체크리스트 항목 | `CHECKLISTS` | 탭 이름과 점검 항목. 현장 작업계획서와 사내 기준에 맞게 수정 |
| FAQ | `FAQ_ITEMS` | 질문(`q`)·분류 배지(`c`)·카테고리 버튼용 분류(`g`, 배지 없음)·출처(`s`)·답변(`a`). 카테고리 버튼은 `c`(없으면 `g`) 값으로 자동 생성됨 |
| 자료실 | `RESOURCES` | 파일명(`name`), 설명(`desc`), 경로(`url`), 용량(`size`) |

문구에 작은따옴표(`'`)를 쓰려면 앞에 `\`를 붙이거나 큰따옴표로 감싸세요. 쉼표나 따옴표가 빠지면 화면이 비어 보일 수 있습니다.

## 5. 자료실에 파일 추가·교체

자료실은 `files` 폴더의 파일을 목록(파일명·설명·용량·다운로드 버튼)으로 보여 줍니다. 목록은 `index.html` 맨 위 `RESOURCES`에 적은 내용 그대로 표시되므로, 파일을 넣은 뒤 아래 항목을 직접 추가해야 합니다.

1. PDF·Word 파일은 `files` 폴더에 넣습니다. 폴더 안의 파일 이름은 영문 소문자와 하이픈만 쓰고, 한글과 공백은 쓰지 않습니다. 예: `safety-rules-form.pdf`
2. `RESOURCES`에 한 줄을 추가합니다.

   ```
   { id: 'rules', name: '안전수칙_양식.pdf', desc: '설명 문구', url: 'files/safety-rules-form.pdf', size: 108531 },
   ```

   | 항목 | 설명 |
   | --- | --- |
   | `name` | 화면에 보이는 파일명이자 내려받을 때 저장되는 이름. 한글 사용 가능 |
   | `desc` | 설명 |
   | `url` | `files/파일명` 상대 경로 |
   | `size` | 파일 크기(바이트). 파일 속성에서 확인해 숫자로 입력하면 KB·MB로 바뀌어 표시됨 |

3. 파일을 다른 것으로 바꾸면 `size`도 함께 고치세요. 용량은 코드에 적은 값이라 자동으로 바뀌지 않습니다.
4. 다운로드 버튼을 누르면 PDF가 새 창으로 열리지 않고 `name`의 한글 이름으로 바로 저장됩니다. `index.html`을 더블클릭해 열 때(`file://`)는 Chrome이 `download` 속성을 무시하므로, 대신 `files/files-data.js`에 들어 있는 파일 데이터로 저장합니다. 웹서버(GitHub Pages 등)에서 열면 `files` 폴더의 파일을 직접 읽어 저장합니다.
5. **PDF를 바꾸거나 추가하면 `files/files-data.js`도 다시 만들어야 합니다.** 다시 만들지 않으면 더블클릭으로 열었을 때 이전 PDF가 저장됩니다. Claude에게 "files-data.js를 다시 만들어 줘"라고 요청하세요.
6. `url`을 비워 두면 빈 양식(텍스트·CSV)을 이 브라우저에서 바로 만들어 내려받습니다. 이때 용량은 `–`로 표시됩니다.

## 6. 배경 영상 바꾸기

- 영상 파일을 폴더에 넣고, `index.html`에서 `gemini-generated-video-08a36b57-no-caption.mp4`를 새 파일명으로 바꿉니다(`<video>` 안의 `source`, 한 곳).
- 영상이 얼마나 진하게 보일지는 같은 파일 맨 위쪽 CSS의 `--hero-video-opacity` 값(0~1)으로 정합니다. 현재 `0.35`. 값이 클수록 진해지고, 너무 진하면 제목이 읽기 어렵습니다.
- 영상 파일이 없으면 영상 없이 기본 화면으로 보입니다.
- 모션 줄이기 설정을 켠 PC에서는 첫 화면 정지 상태로 보입니다.

## 7. 색·글꼴

포털의 색·글꼴·여백 기준은 '우리 부서 포털' 디자인 시스템에 정리되어 있습니다. 파스텔 카드는 powder(파랑)·mint(초록)·amber(주황) 세 가지입니다. 색을 바꿀 때는 `index.html` 맨 위 CSS의 `:root` 안 변수를 고치면 한 번에 반영됩니다.

## 8. 자주 생기는 문제

| 증상 | 확인할 것 |
| --- | --- |
| 첫 화면에 영상이 안 나옴 | mp4 파일이 `index.html`과 같은 폴더에 있는지, 파일명이 `index.html` 안의 이름과 같은지 확인 |
| 자료실 다운로드가 안 됨 | `files` 폴더 안에 파일이 있는지, `RESOURCES`의 `url` 경로와 파일명이 같은지 확인 |
| 자료실에서 옛날 PDF가 저장됨 | `files/files-data.js`를 다시 만들었는지 확인(PDF를 바꿨다면 필요) |
| 자료실 용량이 실제와 다름 | `RESOURCES`의 `size`는 직접 적은 값이므로 파일 크기에 맞게 수정 |
| 수정 후 화면이 비어 보임 | 수정 영역의 쉼표·따옴표·괄호가 빠지지 않았는지 확인. 안 되면 `이전버전`의 파일로 되돌리기 |
| 체크 상태나 입력값이 사라짐 | 정상입니다. 저장하지 않으므로 새로고침하면 초기화됩니다 |

## 9. 확인 필요

- 위험도 등급 구간, 체크리스트 항목, FAQ 답변은 일반 안내용 예시입니다. 사내 규정·현장 안전보건 계획·발주처 지침을 확인한 뒤 사용하세요.
- 법령 개정 카드는 비어 있습니다. 국가법령정보센터·고용노동부에서 현행 내용을 확인해 직접 입력하세요.

## 공개 전 참고

- 공개할 때 올릴 파일은 `index.html`, `files/`(preview.png 포함), `gemini-generated-video-08a36b57-no-caption.mp4`입니다. `이전버전/`은 올리지 않습니다.
- 법령 개정 카드(`LEGAL_UPDATES`)가 모두 비어 있으면 해당 섹션과 상단 메뉴 항목이 자동으로 숨겨집니다. 내용을 한 칸이라도 입력하면 나타납니다.
- 링크 공유 미리보기(제목·설명·이미지)는 `index.html` 맨 위 `og:` 태그에 있습니다. 이미지는 `files/preview.png`(1200×630)이고, 주소는 `https://ikna0072.github.io/dept-portal/`로 적혀 있으므로 공개 주소가 바뀌면 모두 바꿔야 합니다. 미리보기는 공개된 주소에서만 보이고, 메신저는 이전 미리보기를 한동안 기억할 수 있습니다.
